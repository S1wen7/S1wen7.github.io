# Hao Wang Academic Homepage

This repository contains the GitHub Pages source for `https://S1wen7.github.io`.

The page is a bilingual academic homepage inspired by the Academic Pages layout:

- English and Chinese language switching on the same page
- Academic profile sidebar
- Education, projects, internship experience, and skills sections
- English and Chinese CV downloads in `files/`

## Deploy

Create a GitHub repository named `S1wen7.github.io`, then push these files to its `main` branch. GitHub Pages will publish the site at:

```text
https://S1wen7.github.io
```

If Pages does not publish automatically, open the repository settings and set **Pages** to deploy from the `main` branch root.
